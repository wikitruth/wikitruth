# Canonical Card: Target State FixPH Extension

## Purpose

Define the intended civic-product extension targets for the FixPH domain.

## FixPH IA Targets

- Complete IA including explicit `Actions`, `Vote Wisely`, and `History`.
- Civic entities across issues, people, groups, organizations, projects, and elections.

## Civic Model Targets

- Government hierarchy graph (institution -> office -> person responsibilities).
- Project accountability model (budget, contracts, timeline, progress, evidence).
- Citizen observation submission with escalation lifecycle tracking.
- Location model and geo-surfacing of incidents/projects.
- Incident stage model with severity progression and outcome history.

## Civic Decision Targets

- Candidate comparison workspace for election decision support.
- Long-term historical memory linking incidents to follow-up actions and outcomes.

## Target State Status

- Overall: `planned`; only shell-level foundations are currently `partial`.
- Source baseline: `docs/system-reference/06_FIXPH_CIVIC_EXTENSION.md` and `docs/plans/plan-2026-04-14/08_VALIDATED_CHECKLIST_CONTENT_FIXPH.md`.
