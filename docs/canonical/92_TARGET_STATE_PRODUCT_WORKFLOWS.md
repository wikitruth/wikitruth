# Canonical Card: Target State Product Workflows

## Purpose

Define the intended future workflow UX and engagement model.

## Authoring and Collaboration Targets

- Inline create/edit/reply on entry pages instead of page-jump-only flows.
- Unified create wizard with context-target selection from global navigation.
- True entry-type conversion flow that preserves history.
- Structured discussion modes including strict debate patterns and thread controls.
- Comment classification routing (`supplement`, `objection`, `question`).

## Discovery and Reading Targets

- Home ranking buckets (`Latest`, `Trending`, `Top`) with explicit formulas.
- Expanded Explore filters (status, tag, relationship, screening) with sharable URL state.
- Role-aware reading modes and stronger archived/outdated UX cues.
- Unified timeline mode plus timeline visualization parity.

## Engagement Targets

- Real persisted reactions decoupled from verdict state.
- Reputation and deterministic badge/scorecard system.
- Backend follow/subscribe delivery model.
- Notification center with unread counts and deep links.

## Target State Status

- Overall: `mixed`.
- Implemented: unified create wizard, history-preserving conversion, expanded Explore controls, role-aware lifecycle views, timeline workflows, persisted reactions, reputation/scorecards, follow/subscription delivery, and notification center.
- Remaining planned: inline entry-page authoring, comment-classification routing, and fully explicit Home ranking buckets.
- Broad strict-debate enforcement is explicitly `deferred` pending governed rules and pilot evidence.
- Source baseline: `docs/plans/deferred/plan-2026-04-14/09_GAP_CHECKLIST_PLAN.md` and `docs/plans/deferred/plan-2026-04-14/07_VALIDATED_CHECKLIST_PRODUCT_WORKFLOWS.md`.
