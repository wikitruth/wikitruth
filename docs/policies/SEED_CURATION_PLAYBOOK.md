# Seed And Curation Playbook

Version: `1.0` (`2026-07-13`)

## Flagship Structure

Each flagship topic or FixPH cluster should include:

- A concise overview and explicit scope.
- Small factual claims with pending or reviewed verdict states.
- Questions and competing explanations.
- Artifacts with provenance and source-quality review.
- Accepted issues that expose unresolved weaknesses.
- Revision-linked discussion and a visible timeline.
- For FixPH: responsible institution or office, location, incident or project stage, actions, and documented outcome history.

## Curation Workflow

1. A reviewer creates the bounded root and empty starter structure.
2. Contributors fill evidence and claim gaps through normal screened submissions.
3. Screeners reject duplicates and route policy questions to reviewers.
4. Reviewers run source-quality and verdict calibration.
5. Publish only when unresolved gaps are visible rather than hidden.
6. Revisit on material new evidence; do not automatically expire the record.

Seed content must use public, attributable evidence. Test fixtures and generated accounts must never be presented as real civic records.
