**Issues**

Tag Types

* Category Tags (Classification, popular/public statement) [Allowed: Author/Reviewer]
* Hierarchy Tags (Parent, Children, Dependencies) -- these are not tags but elements [Author/Reviewer]
* Issue Tags [Author/Reviewer]
  + Critical - for comments, blocks the discussion; If personal opinion, nihilist/existentialist view, irrational
  + Warnings - shows warning but does not cause restrictions
* Reliability Tags [Reviewer]
  + Logic/reason/argument quality
  + Sources quality or logically derived
* Reality Tags [Reviewer]
  + Overall truthfulness, reality
  + Green, yellow, red combinations for topics
* Property Tags (applies to all actions, elements) [System]
  + Date published, last editor
  + Author, Editor

Issue Types

* Logical fallacy
* Terminology issue (word definition)
* A moral argument (not epistemological)
* Containing unsubstantiated assumption (need to add support)
* Confusing statement structure, too vague (grammatical issue)
* Others

Issue tagging

* For major issues, blocks the discussion thread and can proceed only if issue tags are resolved. The person or side who did the issue will not be able to reply until issue is resolved. This can be more flexible and fluid
* If the argument’s primary gist is a logical fallacy, then it can easily be assigned verdict as False.
