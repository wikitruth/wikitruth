**Change Request (CR)**

1. Any number of contributors can submit a CR on a topic or argument which will be tagged to the current version of the item. Users can view pending and accepted CRs like a diff (before/after). A CR can be a combination of the following against a portion of an item:
   1. Addition
   2. Deletion
   3. Edit/Amendment
2. A reviewer can accept/reject a whole or part of a CR.
3. Once a CR is accepted, the item’s version increases and other pending CRs will become outdated and others may become conflicting.
   1. Outdated but non-conflicting CRs can still be accepted without issues.
   2. Once a conflicting CR is reviewed, the reviewer have the choice to notify the contributor to update the CR or he can do the update/merging himself manually without the action of the contributor.
   3. If a CR is manually merged and the contributor find the merge incorrect or has affected the content, he can flag the merge as having an issue and other reviewers can review the flag and take action.
4. All merges will be recorded as history and can be rolled back if necessary by the power of more than one reviewers.

**Editing, Pull Requests (PR)**

* Applies to Topic, Argument, Comment
* Editing should be always encourage to improve existing content. Adding more content instead of improving the existing crowds the system.
* Happens during discussion. A user can suggest direct edit (diff) or suggest points like bulleted list link to the section (like a Doc comment)
* If multiple suggestions exist about a topic or argument, a merge request discussion can happen

No existing item, first time posting

* Pending state - no reviews, no tags, unconfirmed

Editing an existing pending item

Editing an existing accepted item

**Notes / Potential scenarios**

* Labels: Suggest Edits
* Authors may have number of credits to force the edits to take effect. However, based on history of the author, he may be banned from doing that.
* The author of a post is automatically a reviewer of edits of his post, others may apply to be reviewers who will get notification (subscribe).
