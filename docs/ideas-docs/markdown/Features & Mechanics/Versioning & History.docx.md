**Versioning & History**

Fragment revision versions discussions (Wikipedia, Github) vs Block-size content discussions

Fragment

* Tracing is per revision
* Discussion is per revision
* No centralized revision for current

Blocks

* Single-thread discussion history
* Issue of revision in the content, obsoletes the previous discussion (how to fix this?)

Verdict

* Can we combine the two? Editing is by block and each block has revision history with discussion?
* A block revision history including discussion is linear, with breakpoints (edits), like a train of thoughts and edits.
