**Consider these mechanics**

* By default, entries are editable by anyone.
* Restricted entries can still receive Edit Suggestions and it’s up to the editor to accept or not.
* The author of an entry has the option to allow others to edit, like assign editors or allow the system reviewers to edit or make it open to anyone.
* The more important or the more attention an entry gets, the system may require the author to assign more editors or else the system will take over and open it to designated reviewers.
* Users can apply to be screeners. This is a simple role for initially screening entries to be flagged as screened. Screened entries more up in the list above unscreen entries, below the verified ones. Initial screening may also raise the basic issues.
* Entries with major issues may be rejected or returned back to author as pending screening with an added issues to be solved and re-screened.
* The system can determine the level of restrictions or approvals/verdict needed based on the attention or contributions an entry had received.
* When evaluation if something is true or not, consider both sides: is there substance to believe this is true? And is there substance to believe this is false?
* Very derogatory content can be tagged with time limit to provide substance, otherwise will be deleted
