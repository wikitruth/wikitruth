# Wikitruth Ideas Archive

This directory contains a curated historical snapshot of Wikitruth product
notes, feature designs, and project-owned visual assets.

## Layout

- `original/` contains editable source documents and project-owned assets.
- `markdown/` contains reviewable text conversions of project documents.

The original Google Drive import manifest, folder identifiers, resource keys,
and sharing URLs are intentionally excluded from version control. Full copies
and text conversions of third-party publications are also excluded unless the
repository has explicit redistribution rights.

See [THIRD_PARTY_CONTENT.md](THIRD_PARTY_CONTENT.md) before adding external
reference material.
