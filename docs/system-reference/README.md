# Google Drive System Reference Hub

This folder is the normalized documentation/reference/ideas hub derived from `docs/ideas-docs`.

## Scope

- Source corpus scanned: **132 files**
- Source basis: markdown conversions, original docx/pdf/xlsx files, design diagram files (`.smmx`, `.gliffy`), and visual assets
- Goal: convert fragmented notes into maintainable system documentation and implementation-grade idea references

## What Was Improved

- Consolidated repeated ideas across backlog/tasks/notes into one normalized model.
- Converted noisy/raw concept notes into cleaner system language and stable terminology.
- Separated **requirements signal** from **external contextual references**.
- Added source traceability so every major section maps back to imported files.
- Added quality notes for politically charged or unverified claim material (treated as raw claim inputs, not facts).

## Usage Guidance

- Treat docs `01` to `06` as system-reference baseline.
- Treat doc `08` as ideation backlog, not as completed implementation status.
- Treat raw allegation-based sources as **claim intake** only; require evidence review before publication as validated content.
