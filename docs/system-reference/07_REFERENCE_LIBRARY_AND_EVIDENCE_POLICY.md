# Reference Library and Evidence Policy

## Purpose

This document separates external/context readings from implementation-grade system requirements.

## Source Quality Bands

1. `Band A: Product-spec sources`
- Wikitruth notes, tasks, backlog, mechanics docs, development phases, FixPH product notes.
- Use as direct requirement candidates.

2. `Band B: Conceptual references`
- fallacies primer, fact-vs-opinion primer, critical-vs-creative thinking articles, governance integrity letter.
- Use to shape policy, moderation guidance, and contributor education.

3. `Band C: External contextual material`
- legal case PDFs, opinion-heavy political texts, broad internet link dumps, screenshot collections.
- Use as context only; not direct requirements.

## Evidence Admission Policy (Recommended)

For publishing as validated content:

1. claim statement is precise and scoped
2. supporting source(s) are linked and reviewable
3. issue tags are resolved or explicitly retained with status impact
4. reviewer decision trail is visible
5. high-risk civic allegations require stricter corroboration

For claim intake only:

- unverified allegation lists,
- screenshots without provenance,
- opinion narratives without evidence chain.

## Operational Guidance

- Do not auto-promote external references into truth status.
- Preserve source attribution for every imported claim.
- Prefer primary records and reproducible evidence over secondary commentary.
